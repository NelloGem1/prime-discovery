📐 The Formulas

For every prime p > 5:
  p % 10 ∈ { 1, 3, 7, 9 }  — the last-digit law
  p % 30 ∈ { 1,7,11,13,17,19,23,29 }  — the mod-30 sieve (only 8 of 30 classes survive)

Find one prime violating either line and the theorem is dead. Nobody has — Lean checked all cases.

🐍 Option A — Python (2 minutes)

Needs Python 3 + sympy (pip install sympy). Tests every prime to 10 million:

verify_primes.py# verify_primes.py — paste into any Python 3 and run import sympy ok1 = ok2 = ok3 = 0 for p in sympy.primerange(7, 10_000_000): if p % 10 in (1,3,7,9): ok1 += 1 if p % 30 in (1,7,11,13,17,19,23,29): ok2 += 1 ok3 += 1 print(f"last-digit law: {ok1}/{ok3} primes pass") print(f"mod-30 sieve: {ok2}/{ok3} primes pass") print(f"counterexamples found: {ok3-ok1} and {ok3-ok2}") # both should be 0

Expected output: every prime passes, counterexamples = 0. (Strong evidence — the real proof is Option B.)
